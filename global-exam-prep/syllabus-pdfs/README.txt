Put your syllabus PDF files here, named as: {subjectId}-{subjectName}.pdf

Examples:
  01ma0106-Calculus.pdf
  01ce1101-Computer Programming.pdf
  01gs1101-Engineering Physics.pdf

Then run from the project root:
  node process-syllabuses.cjs

This will generate src/data/pdfSyllabus.js which ExamPortal uses automatically.
