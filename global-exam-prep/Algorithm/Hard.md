# Difficulty Overlay — Hard

Append these instructions to exactly one selected exam prompt.

## Intended cognitive demand
Require substantial but fair reasoning: multiple meaningful steps, integration of related syllabus concepts, analysis of constraints, diagnosis/debugging, calculation, comparison of competing approaches, or handling of relevant edge cases.

## Construction rules
- Combine concepts only where the syllabus supports the connection; cross-topic integration should be substantive rather than decorative.
- Include enough facts, data, assumptions and constraints for the task to be solved. Never rely on hidden assumptions.
- MCQ distractors should be technically plausible, including near-miss solutions, incomplete approaches, a correct rule used outside its assumptions, or a realistic intermediate error. The keyed option must be the only one satisfying all explicit conditions.
- Theory questions should demand depth appropriate to the marks. Model answers and marking rubrics must show the reasoning and award credit for valid intermediate steps.
- Use complex calculations, code/debugging, trade-offs or edge cases only when the subject content supports them.
- Hardness must not come from obscure trivia, excessive length, vague wording, double negatives or multiple defensible answers.
- Stay within the verified syllabus and the selected exam's coverage rules.
