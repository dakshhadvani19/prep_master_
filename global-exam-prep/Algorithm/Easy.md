# Difficulty Overlay — Easy

Append these instructions to exactly one selected exam prompt.

## Intended cognitive demand
Assess fundamentals, definitions, core principles, direct interpretation and straightforward application of one principal concept at a time. A student who understands the basic syllabus concept should be able to solve the question without multiple hidden steps.

## Construction rules
- Prefer one main concept and one decisive reasoning step.
- Numerical questions should use straightforward values and clearly stated units/assumptions.
- Theory questions should ask for a precise definition, basic explanation, direct comparison or simple application appropriate to the question's marks.
- MCQ distractors must still be credible: use common beginner misconceptions or nearby concepts, not absurd choices.
- Do not reveal the answer through grammatical cues, option length or an obvious pattern.
- Avoid trick wording, unnecessary context, obscure facts and ambiguity.
- Easy does not mean trivial, irrelevant or outside the actual course level. Stay within the supplied syllabus and exam blueprint.
