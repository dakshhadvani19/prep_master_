PREPMASTER FEEDBACK — REMOVED RATING UI ARCHIVE
================================================

This file preserves the rating UI removed from FeedbackPage.jsx.
It is plain text only and is not imported by the application.

The source was the pre-removal FeedbackPage.jsx. The former rating UI
used inline React styles and Lucide's Star icon; it did not have a
separate stylesheet or a dedicated rating keyframes animation.
The hover/focus feedback used hoveredStar state and the inline
transform transition shown below.

1. Former import and state
--------------------------

import { MessageSquare, Send, Star, ChevronLeft, CheckCircle, Loader, AlertCircle } from 'lucide-react';

const [formData, setFormData] = useState({
    type: 'general',
    rating: 0,
    description: '',
});
const [hoveredStar, setHoveredStar] = useState(0);

const handleChange = (field, value) => {
    setFormData((previous) => ({ ...previous, [field]: value }));
};

2. Former validation and request payload
----------------------------------------

if (formData.rating < 1 || formData.rating > 5) {
    setStatus('error');
    setErrorMsg('Please select a rating from 1 to 5.');
    return;
}

body: JSON.stringify({
    type: formData.type,
    rating: formData.rating,
    description,
})

const canSubmit = Boolean(
    studentId && session?.access_token && formData.description.trim()
    && formData.rating >= 1 && status !== 'loading'
);

3. Former rating JSX
--------------------

<div>
    <label
        style={{
            display: 'block',
            fontWeight: 600,
            marginBottom: '0.875rem',
            fontSize: '0.95rem',
        }}
    >
        Only Rating
        {formData.rating > 0 && (
            <span
                style={{
                    color: 'var(--text-secondary)',
                    fontWeight: 400,
                    marginLeft: '0.5rem',
                }}
            >
                {formData.rating}/5
            </span>
        )}
    </label>

    <div
        style={{ display: 'flex', gap: '0.5rem' }}
        role="group"
        aria-label="Only Rating"
    >
        {[1, 2, 3, 4, 5].map((star) => (
            <button
                type="button"
                key={star}
                aria-label={`Rate ${star} out of 5`}
                aria-pressed={formData.rating === star}
                onMouseEnter={() => setHoveredStar(star)}
                onMouseLeave={() => setHoveredStar(0)}
                onFocus={() => setHoveredStar(star)}
                onBlur={() => setHoveredStar(0)}
                onClick={() => handleChange('rating', star)}
                style={{
                    background: 'none',
                    border: 'none',
                    cursor: 'pointer',
                    padding: '4px',
                    transition: 'transform 0.15s',
                }}
            >
                <Star
                    size={32}
                    fill={(hoveredStar || formData.rating) >= star
                        ? '#fbbf24'
                        : 'transparent'}
                    color={(hoveredStar || formData.rating) >= star
                        ? '#fbbf24'
                        : 'rgba(255,255,255,0.2)'}
                />
            </button>
        ))}
    </div>
</div>

4. Former visual behavior
-------------------------

- Five selectable Star icons represented values 1 through 5.
- Hover and keyboard focus temporarily previewed the active star range
  through hoveredStar.
- Leaving or blurring the star button reset the preview to zero.
- Selected stars were filled yellow (#fbbf24); unselected stars were
  transparent with a muted outline.
- The star buttons used a 0.15-second transform transition.
- The selected value was displayed beside the label as N/5.

No rating state, markup, validation, request field, star interaction,
or rating styling from this archive is active in the current page.
The current feedback form submits only type and description.
