MARWADI UNIVERSITY DIPLOMA SYLLABUS COLLECTOR

IMPORTANT: This is a locally-run source collector, not a pre-downloaded finished syllabus archive. The execution environment used to build this package cannot download the PDFs from the university; therefore the actual PDFs are fetched on your Windows PC from Marwadi University's official website.

It uses only these official pages:
- https://www.marwadiuniversity.ac.in/computer-engineering-diploma/
- https://www.marwadiuniversity.ac.in/mechanical-engineering-diploma/
- https://www.marwadiuniversity.ac.in/chemical-engineering-diploma/
- https://www.marwadiuniversity.ac.in/electrical-engineering-diploma/
- https://www.marwadiuniversity.ac.in/civil-engineering-diploma/
- https://www.marwadiuniversity.ac.in/ict-diploma/

It does NOT read subjects from Supabase or GitHub.

HOW TO RUN
1. Extract the entire ZIP to a normal folder, for example Downloads\Marwadi_Official_Diploma_Collector.
2. Keep internet connected.
3. Double-click RUN_FULL_COLLECTION.bat.
4. Wait for it to finish. First-time setup installs three dependencies in an isolated .venv.
5. Open Marwadi_Diploma_Complete_Syllabus_Collection.zip in the same folder. It is generated by the run.
6. Read Reports\SUMMARY.txt and the CSVs before claiming every syllabus is complete.

OUTPUT FOLDERS
- Verified_Syllabi: the PDF text contains the official subject code and an adequate title match.
- Needs_Review: official syllabus candidates whose internal code/title evidence did not meet the exact verification threshold.
- Other_Official_Page_PDFs: direct official PDFs whose course/subject association is not explicit enough to file as a verified subject.
- Reports: every page-listed title/code, download source, SHA-256, status, direct link and unresolved result.

This intentionally preserves the PDFs Marwadi actually links or indexes even when internal metadata mismatches; it does not silently throw them away. It never labels an HTTP error, timeout, or rate limit as a missing syllabus. No Supabase, GitHub, website, or live catalog data is changed.
