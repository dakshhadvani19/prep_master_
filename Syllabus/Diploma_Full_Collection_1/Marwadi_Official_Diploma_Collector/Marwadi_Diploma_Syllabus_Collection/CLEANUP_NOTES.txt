Repository cleanup note — 2026-10-12

This cleanup removes 84 repeated, non-syllabus administrative PDF copies from
Other_Official_Page_PDFs across the six Diploma program folders. The removed
files were 14 identical documents repeated once per department, including
university statutes, fees information, LMS material, policies, institutional
cells and administrative forms. They were not course syllabi.

The 7 remaining PDFs in Other_Official_Page_PDFs whose names contain course
titles/codes are preserved. All Verified_Syllabi PDFs, Needs_Review PDFs,
Reports, collector scripts, requirements, launchers and README files are
preserved. The scratch file Syllabus/1.txt is removed.

Reports describe the original collector run and may contain the original
download inventory, before this manual cleanup. They are retained for audit
and provenance. Re-running the collector may download some administrative
documents again from official pages.

Approximate working-tree file payload removed: 192.31 MiB.
This does not erase historical Git objects; earlier commits retain references.
