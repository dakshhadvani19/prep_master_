This collection was rebuilt from the six official Marwadi University Diploma course pages and Marwadi's own media index. It does not use the Supabase subject list.

Folders:
- Verified_Syllabi: PDF text included the current official subject code and a sufficient title match.
- Needs_Review: official candidate files need manual review because code/title evidence is incomplete or mismatched.
- Other_Official_Page_PDFs: direct PDFs linked on official course pages but not associated to a code/title with enough confidence.
- Reports: exact course-page subject inventory, direct links, hashes, statuses and failures.

See Reports/SUMMARY.txt before claiming completion. The university may list some subjects without an accessible PDF. No web extraction process can guarantee a PDF that Marwadi does not publish or that its server will not serve.
