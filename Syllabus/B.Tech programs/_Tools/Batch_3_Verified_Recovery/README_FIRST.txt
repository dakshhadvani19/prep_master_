## Run

1. Run `RUN_RECOVERY.bat` from this folder on Windows.
2. New recovery output is written temporarily under `Output/`; validation details remain in `Reports/`.
3. `collection_roots.txt` points the runner at `..\..\_PDF_Library` so existing unique files can be reused after content checks.
4. Do not commit `Output/` as a second collection. Review and deduplicate new PDF content against the canonical library before updating the catalog.

The retained recovery manifest, PDF validation report, and `data/` files document the original run, including verified files and unresolved course rows. A previous failed search is not proof an official syllabus is unavailable.
