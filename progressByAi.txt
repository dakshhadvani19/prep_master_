==============================================================================
  1. PROJECT OVERVIEW
==============================================================================

"Global Exam Prep" is a web app for students preparing for exams.

It allows students to:
  - Browse courses/subjects organized by domain
  - Take AI-generated exams (MCQ-style) with difficulty levels
  - Review past exam performance on a dashboard
  - Search across subjects and courses

Stack:
  - Framework : React 19 + Vite 7 (inside folder: global-exam-prep/)
  - Routing   : react-router-dom v7
  - Auth/DB   : Firebase (Auth + Firestore + Storage) v12
  - AI        : Google Generative AI (@google/generative-ai)
  - Animations: Framer Motion v12
  - Icons     : Lucide React
  - Deployment: Vercel

Root folder structure:

  4. AUTHENTICATION SYSTEM (Current State as of 2026-08-31)
==============================================================================

FILE: src/context/AuthContext.jsx

Firestore Collection: students
  Each document ID = Firebase Auth UID
  Fields:
    - studentId    : number  (auto-incremented integer via getNextStudentId())
    - uid          : string  (Firebase UID)
    - fullName     : string
    - email        : string  (lowercase trimmed)
    - passwordHash : string  (SHA-256 of "password:email")
    - isSpam       : boolean
    - provider     : string  ('email' or 'google')
    - providers    : string[] (['email'] or ['google'])
    - createdAt    : string  (ISO timestamp)
    - photoURL     : string or null

Auth methods exposed via useAuth() hook:
  - login(email, password)                    -> Firebase email/password sign-in
  - signupWithEmail(email, password, name)    -> Creates Firebase user + Firestore doc
  - signInWithGoogle()                        -> Google popup, returns { user, isNewUser }
  - completeGoogleProfile(user, name, pass?)  -> Saves Google user to Firestore
  - checkEmailExists(email)                   -> Checks Firestore 'students' collection
  - sendPasswordReset(email)                  -> Firebase password reset email
  - logout()                                  -> Clears localStorage + signs out

Auth State available via useAuth():
  - currentUser  : Firebase user object (null if not logged in)
  - studentData  : Firestore student document data
  - authLoading  : true while resolving initial auth state
  - isAdmin      : HARDCODED false (admin system NOT implemented yet)
  - isSuperAdmin : HARDCODED false (admin system NOT implemented yet)

Email Signup flow:
  Step 1 -> User enters email
  Step 2 -> OTP sent to email (via otpService.js)
  Step 3 -> User verifies OTP
  Step 4 -> User fills name + password
  Step 5 -> signupWithEmail() creates Firebase Auth user + Firestore student doc

Google Signup flow:
  Step 1 -> User clicks "Continue with Google" -> Google popup
  Step 2 -> If new user: show name + optional password form
  Step 3 -> completeGoogleProfile() saves to Firestore
  Step 4 -> If returning user: navigate directly to /dashboard

  5. ROUTING & AUTHENTICATION PAGES
==============================================================================

Routes defined in App.jsx:
  /                                       -> LandingPage (public)
  /login                                  -> Redirects to /signup?mode=login
  /signup                                 -> Signup.jsx (combined auth page)
  /signup?mode=login                      -> Shows login tab by default
  /signup?mode=signup                     -> Shows signup tab by default
  /domains/:domainId/courses              -> CourseExplorer (public)
  /search                                 -> SearchResults (public)
  /feedback                               -> FeedbackPage (public)
  /guide                                  -> UserGuide (public)
  /courses/:courseId/subjects             -> SubjectDetails (public)
  /exams/:subjectId/:examType/:difficulty -> ExamPortal (PROTECTED)
  /dashboard                              -> Dashboard (PROTECTED)
  /review/:historyId                      -> ReviewPage (PROTECTED)
  /admin/syllabus                         -> SyllabusAdmin (PROTECTED)

IMPORTANT - Signup.jsx is the UNIFIED auth page:
  - Contains a SegmentedControl (iOS-style tab): "Create account" | "Log in"
  - Reads ?mode from URL to pre-select the correct tab on load
  - Mode logic (Signup.jsx line ~107):
      const [mode, setMode] = useState(urlMode === 'login' ? 'login' : 'signup');
  - Also supports ?method=email (opens email form directly)
  - Also supports ?method=google (auto-triggers Google popup)

KNOWN BUG (as of 2026-08-31):

  6. PROTECTED ROUTES
==============================================================================

FILE: src/components/ProtectedRoute.jsx

Behavior:
  - If authLoading -> render null (AuthProvider shows its own full-page spinner)
  - If not logged in -> redirect to /signup, preserving intended path in location.state
  - If requiredRole='admin' and user is not admin -> redirect to /dashboard
  - If requiredRole='superAdmin' and not superAdmin -> redirect appropriately
  - If all checks pass -> render children
